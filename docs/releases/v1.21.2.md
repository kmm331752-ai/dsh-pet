## 🐛 「桌宠又不能用」的真因：运行时丢了两个包，而它不吭声

你报的是「现在桌宠又不能用了」。查下来是**四件事**，其中一个是真凶。

---

### 真凶：DSH 重装运行时，丢了依赖

```
❌ zstandard    读 DSH 会话日志（任务状态 / 踩过的坑全靠它）
❌ pywin32      托盘相关
❌ pystray      也丢了，但那个不明显（只是托盘起不来）
```

`pystray` 早上 07:59 在日志里留了一条 `ModuleNotFoundError`。
**`zstandard` 一条都没有** —— 因为代码里是这么写的：

```python
try:
    import zstandard
except ImportError:
    zstandard = None          # 然后 _iter_events 直接 return
```

**降级本身是对的**（没装 DSH 的人不该崩），错的是**不说**。
你看到的是「桌宠不能用」，日志里干干净净。

装上就恢复了。

---

### 🐛 顺手抓到三个真 bug

**① `P.TaskInfo` —— 单文件重构的残留**

```python
tasks = list(self.snap.tasks) or ([P.TaskInfo(...)] if ... else [])
```

`P` 是拆模块之前「本模块自己」的别名，早就不存在了。

后果：**「右键 → 会话」在没有活跃任务时抛 `NameError`**，被 Tk 的
回调异常处理器接住写日志 —— 窗口不弹，你只会觉得「点了没反应」。

**② 单实例锁失败 = 静默死亡**

```python
print(f"...", file=sys.stderr)
return 2
```

**`pythonw.exe` 下 stderr 是黑洞。** 开机自启最容易撞上「上一只还没退干净」
（端口约 2 秒才释放），这一只就一声不响地退出。

改两件：

- **重试 3 秒**（开机抢跑等一下就好）
- 真失败就**写进 `pet_error.log`**

顺手把这段从 `main()` 里提成 `acquire_single_instance()` —— 内联的时候
根本没法写测试，只能真起两个进程验。

**③ `repair_autostart` 每天误报一次**

```
[10-28 08:03:46] 自启命令指错了，已改回：
  ...\DeepSeekwork\...  ->  ...\DeepSeekwork\...
```

两边看着一模一样 —— 差的是**大小写**。Windows 路径不区分大小写，
字符串 `==` 区分。改成比之前先 `os.path.normcase()`。

### ✅ 新增：启动时检查依赖，缺了就说清楚

```
[error] 缺少依赖：zstandard（读 DSH 会话日志）。
        装上就能恢复：pip install zstandard
```

这样下次「不能用」能直接看出是缺包，而不是猜。

### 🧪 测试 453 → 464

`tests/test_startup.py` 11 条，拦的都是**开机那一瞬间**的问题：

| 测试 | 拦什么 |
|---|---|
| `test_waits_for_a_slow_release` | 占住端口 0.4 秒再释放，新实例**必须等到** |
| `test_opens_without_any_task` | 没有任务时「右键 → 会话」不许抛 NameError |
| `test_no_bare_P_references_in_source` | 扫源码，别再留 `P.XXX` |
| `test_case_only_difference_is_not_a_repair` | 只差大小写不许当「指错了」 |
| `test_reports_missing_and_logs_how_to_fix` | 缺包要写日志且给出 `pip install` |

**两个都验证过真能拦住**：把 `P.TaskInfo` / `normcase` 临时改回去，
对应的测试立刻红。
