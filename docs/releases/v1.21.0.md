## 🐾 光标在屏幕另一头动，她会走过来

以前她**只会看，不会来** —— 光标跑到屏幕另一头，她只是把头转过去。

现在：**看 → 过来 → 再看一眼。**

---

### 抄了一个 20 年前的东西，但改了四个地方

翻开源项目的时候又看了一遍 [oneko](https://github.com/adryd325/oneko.js)（1331★ MIT）
—— 就是那只追着鼠标跑的猫。它的核心只有三行：

```js
if (distance < 48) { idle(); return; }        // 够近就别追了
nekoPosX -= (diffX / distance) * nekoSpeed;   // 朝光标走
```

**但 oneko 是永远追。** 那是它的 charm，也是它出名地有点烦的原因。

所以加了四个刹车：

| 限制 | 为什么 |
|---|---|
| **光标得在动**（2.5 秒内） | 你不动她就不来 |
| **够近就不追**（110px） | 不会扑到光标上 |
| **追太久就放弃**（8 秒） | 不跟着跑到天涯海角 |
| **没力气不追** + 目标夹进屏幕 | 追不出屏幕 |

顺序也和 oneko 一致：它先出一帧 `alert` 再起步，这里是先 `gazing` 看你，
看完了才动身。

---

### 💬 一个诚实的技术说明

**那 16 个方向的素材是「视线」，不是「走路」。**

拿它们当走路循环会变成**滑行** —— 身体帧不变、窗口位置在挪，看起来像
在冰上滑。

所以：

- **走路**用已有的 `running` 行走动画（行 1），靠 `mirror` 换向
- **到位停下**时切 `gazing`，用 16 个方向**正对着你看**

素材用在该用的地方，不硬凑。

### 🐛 这轮抓到两个

**1. 顺序错了。** 第一版把追鼠标放在转头**前面** —— 光标一远她二话不说就
走过去，没有「看过来」那一下。而且两条 gaze 测试直接挂（`'chasing' != 'gazing'`）。

改成：`gazing` 看完还在远处，才切 `chasing`。

**2. 一条飘了很久的测试，根因是它自己写错了。**

`test_health_reminder_survives_quiet` 连跑十几遍会挂一两次，单独跑永远绿。
最后一句是：

```python
self.assertTrue(app.snap.quiet, "quiet 标记本身还在")
```

但 `decorate()` 里明明是：

```python
if now < self._quiet_until and not self.bubble_important:
    snap.quiet = True
```

**important 气泡在的时候 quiet 本来就不该为真。** 那句断言之所以通常能过，
只因 `_health_tick()` 跑在 `decorate()` **之后** —— 纯属时序巧合。

拆成一对：

- `test_health_reminder_survives_quiet` —— 重要气泡穿过 quiet
- `test_chitchat_is_suppressed_by_quiet` —— **另一半**：闲聊确实被压

只有一条的话，「quiet 太狠」和「quiet 没用」看起来是一样的。

**连跑 8 遍 0 失败。**

### 🐛 CI 又抓到我一次

```
AssertionError: 'idle' != 'chasing'
```

`_try_chase()` 第一句是 `if night: return False`，而 `_night()` 看的是
**本机时钟**。CI runner 是 UTC，跑的时候本地时间落在夜里 → 一次都不追。

**本地全绿，CI 两个 Python 版本一起挂。** 因为我在 +08:00，测试跑的是白天。

> 这是「测试不许依赖机器状态」的第 N 次。前面记过系统空闲时间、界面语言、
> 时钟刻度、动画相位 —— **这次是昼夜时段**。
>
> 修法：`setUp` 里把 `_night` 钉死；验证时用 `TZ=UTC` 模拟 CI
> （本地时 = 1 点，正是夜里）再跑一遍。

### 🧪 测试 426 → 440

`tests/test_chase.py` 13 条，全走 `poll()`：

| 测试 | 拦什么 |
|---|---|
| 远处 + 光标在动 → 先 `gazing`，看完了 `chasing` | 顺序 |
| **够近 / 光标停了 / 没力气 → 都不追** | 变成 oneko 那种烦人 |
| 追到 → 切 `gazing` | 16 方向素材用在这儿 |
| 追太久 / 你不动了 → 放弃 | 卡在 chasing |
| 目标夹进屏幕 | 追出屏幕 |
| `wander_step` 比 `WANDER_STEP` 快、不在追时是 0 | 散步过来 vs 赶过来 |
| 新状态在 `PALETTE` 里有颜色 | 信息卡没颜色 |
